# Корзина Сатурн — подарок за покупку от 1000 ₽

React + TypeScript + Vite, без backend. Одно приложение с пятью состояниями сценария и вычисляемым правом на один бесплатный подарок.

## Запуск

```sh
npm install
npm run dev
```

`npm test` — 12 тестов бизнес-логики. `npm run build` — проверка TypeScript и сборка. `dist/index.html` — полностью автономный HTML: CSS, JavaScript, React и SVG-изображения встроены. Файл можно открыть локально без сервера.

`prototype.html` и `docs/index.html` — проверенные копии последней сборки. После изменений выполните сборку и скопируйте `dist/index.html` в оба файла.

## Подтверждённый состав акции

По уточнению пользователя участвуют ровно пять товаров: начальный Vetonit Ultra Fix за 555 ₽, штукатурка за 444 ₽, клей за 700 ₽, цемент за 578 ₽ и цемент за 624 ₽. В поп-апе четыре товара; цемент за 662 ₽ исключён по прямому указанию пользователя.

Начальная сумма акции 555 ₽, не хватает 445 ₽. Добавление 444 ₽ даёт 999 ₽ и не активирует подтверждение. Две единицы по 444 ₽ дают 1443 ₽; товар за 700 ₽ — 1255 ₽. Подарок появляется только после подтверждения черновика или увеличения количества в самой корзине. При потере порога исчезает, при восстановлении появляется снова. Он всегда один и бесплатный.

Поиск и выбор чекбоксами работают; итог заказа включает только выбранные позиции. Условие акции считается по всем участвующим товарам в корзине, независимо от чекбоксов, согласно формуле задания. Другие товары, услуги и подарок в порог не входят.

В макетах итог 10 725 ₽ не равен сумме цен отдельных строк (две строки по 44 120 ₽). Для корректного динамического пересчёта использованы реальные суммы отображённых цен, а не несогласованный итог макета. Четвёртая неакционная позиция Granit Fix за 967 ₽ взята из финального макета. Для неакционных позиций использованы стоимости строк. Различные суммы на макетах намеренно не подменяют арифметику приложения.

Изображения товаров и знак логотипа — локальные SVG-иллюстрации упаковок. Оригинальные фотографии отдельно не предоставлены. Второстепенные сервисы работают как демонстрационные уведомления; данные не отправляются на backend.

## Проверено

12 тестов: состав пяти участников, пороги 999/1000, 2000/3000, количество, бесплатность и единственность подарка, объединение без дублей, отсутствие изменений до подтверждения, выбор и итоги.

Браузерный прогон прошёл A–E: добавление/подтверждение, 999 → 1443, один подарок при суммах свыше 3000, потеря/восстановление права, все четыре способа закрытия и сброс черновика. Также проверены Tab/Shift+Tab, возврат фокуса, блокировка фоновой прокрутки, поиск, переключение покупателя, чекбоксы, очистка с подтверждением и мобильный экран. Автономный HTML проверен отдельно.
